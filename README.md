# Restricted Text Area

A simple web project featuring a restricted text area that allows users to enter a maximum of **250 characters**. It includes a live character counter that updates as the user types, helping users keep track of their remaining characters.

## Features

* **250-Character Limit:** Prevents users from entering more than 250 characters.
* **Live Character Counter:** Displays the current character count out of 250.
* **Real-Time Updates:** Updates the counter whenever text is added or deleted.
* **Simple UI:** A clean and easy-to-use interface.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Use

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Start typing in the text area.
4. Monitor the character counter to keep track of your 250-character limit.

## Project Purpose

This project was built to practice HTML, CSS, and JavaScript, particularly DOM manipulation, event handling, and input validation.
